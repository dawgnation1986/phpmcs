private function updateFluidCell(int $x, int $y, int $z, int $kind): bool
{
    if ($y < 1 || $y > 255) return false;
    $state = $this->blockStateAt($x, $y, $z);
    if ($state < 0) return false;
    $id = $state >> 4;
    $meta = $state & 15;

    $source  = $this->fluidSourceId($kind);     // 水 9
    $flowing = $this->fluidFlowingId($kind);    // 水 8

    // 水源：不动，只往外扩
    if ($id === $source && $meta === 0) {
        $this->spreadFrom($x, $y, $z, $kind, 0);
        return false;
    }

    if ($id !== $flowing) return false;

    // ★ 上一轮为了修「倒出水立刻消失」加的补丁
    if ($meta === 0) {
        $this->spreadFrom($x, $y, $z, $kind, 0);
        return false;
    }

    $want = $this->computeLevel($x, $y, $z, $kind, $meta);

    if ($want === null) {
        $this->changeBlock($x, $y, $z, 0, 0);          // 没来源 → 删
        $this->notifyFluidNeighbors($x, $y, $z, $kind);
        return true;
    }

    if ($want !== $meta) {
        $this->changeBlock($x, $y, $z, $flowing, $want);
    }
    $this->spreadFrom($x, $y, $z, $kind, $want);

    return $want !== $meta;
}

### `computeLevel()` — FluidTrait:173

```php
private function computeLevel(int $x, int $y, int $z, int $kind, int $current): ?int
{
    $source  = $this->fluidSourceId($kind);
    $flowing = $this->fluidFlowingId($kind);
    $reach   = self::FLUID_REACH[$kind];

    // ★ 同上补丁：meta 0 的流动水按源级处理
    if ($current === 0) return 0;

    // ① 正上方是同种流体 → 落下来的水（meta 8 + 上方等级）
    $above = $this->blockStateAt($x, $y + 1, $z);
    if ($above >= 0 && $this->isFluidId($above >> 4)
        && $this->fluidKindOf($above >> 4) === $kind) {
        $am = $above & 15;
        return min(15, $am >= 8 ? $am : $am + 8);
    }

    // ② 水平找最近来源
    $best = null;
    foreach ([[1,0],[-1,0],[0,1],[0,-1]] as [$dx, $dz]) {
        $nb = $this->blockStateAt($x + $dx, $y, $z + $dz);
        if ($nb < 0) continue;
        $nid = $nb >> 4;
        $nm  = $nb & 15;

        // ★ 这里把「meta 0 的流动水」也当成源（best = 0）
        if ($nid === $source || ($nid === $flowing && $nm === 0)) {
            $best = 0;
            continue;
        }
        if ($nid === $flowing && $nm < $reach) {
            $best = $best === null ? $nm : min($best, $nm);
        }
    }

    if ($best === null) return null;
    $want = $best + 1;
    return $want > $reach ? null : $want;
}
```

## 三、仍然存在的三个症状（附截图描述）

### 症状 A：填掉一格水，周围的水不退 / 局部变成水源

操作：池子里拿方块填掉一格。

结果：那格确实变成方块了，但**周围的水还在流**，而且**某些特定格子变成了水源**（静止水外观），  
于是整片水退不掉。

日志（上一轮）：

```
[08:58:50] 倒出水 @ -16,62,-28      ← 128 = 8<<4，流动水
[08:58:50] 替换方块 128 @ -16,62,-28
（连续倒了 8 次，每次都写同一格）
```

我的猜想：`computeLevel` 里 `$nid === $flowing && $nm === 0` 被当成 `best = 0`（源级），  
所以「玩家倒出来的 meta 0 流动水」在别的水看来就是一个水源 ——  
于是 3 格池中间满足“2 个相邻水源” → 升级成水源，然后左右又各自满足 → 连锁。

但 `spreadFrom` 的源计数**只数 `id === 9`**，不数 8。两处判定不一致，这里可能是我搞错了。

### 症状 B：3 格水池，中间成源、两边是流动水

```
[水] [水] [水]     ← 视觉上中间是静止水，两边是流动水（有流动纹理）
```

用户预期：既然中间已经成为水源，两边也应该被算成“相邻两个水源”从而升级。

我的疑问：原版里两边应该升级吗？还是保持流动？如果应该升级，那我们的判定条件写窄了。

### 症状 C：重启后水面“成膜”

重启服务端再进游戏，原本的水池变成一层像玻璃/薄膜的东西（截图 4、5）。

我的猜想：存档里的水存的是 `meta 8~15`（下落水状态），客户端按“瀑布”渲染，  
所以看起来是整块而不是水面。这可能是我们历史上的瀑布逻辑写进去的，  
也可能是 `spreadFrom` 的 `changeBlock(..., $flowing, 8)` 在没有下方空间时也写了 8。
